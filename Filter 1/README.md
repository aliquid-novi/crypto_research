### Filter 1

Use this folder as a "research sandbox" where you use https://github.com/bmoscon/cryptofeed data feed to search for potential alpha opportunities, then whatever survives, use the institutional data at work. Note this would be geared towards very general research/over-arching relationships, i.e. btcusdt on exchange a tends to lead btcusdt on exchange b.  

**Staging Process**

1. Public Research Environment. Let it search for:
   - lead/lag relationships;
   - basis relationships;
   - funding relationships;
   - order-flow persistence;
   - cross-exchange imbalance;
   - liquidity regime changes;
   - volatility relationships;
   - price dislocations;
   - potential hedge instruments.

2. Public Data Backtest
    - Test if the relationship is statistically/economically meaningful.
    - Use statistics like IC, t-stats, half-lives, conditional returns and regime stability

3. Internal Validation
    - Evaluate the hypothesis now using the firms data:
    - Actual timestamps + actual books + actual fills + actual fees + actual latency

General guide is to give AI market structure data points like:

- Book_a, Book_b, trades_a, trades_b, funding

and then ask it to do a search of economic mechanisms. The more specific, the better. For example, "Identify persistent relationships between aggressive trade flow A and subsequent changes in B, propose economic explanations, and suggest falsification tests."
